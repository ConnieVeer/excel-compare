How to compare two Excel files

  1. Upload the old version as File A and the new version as File B.
  2. Pick a key column that identifies each row, like a customer ID. The tool suggests one for you.
  3. Click Compare. You see which rows were added, removed or changed, and which cells differ.
  4. Choose a format (.xlsx, .xls or .csv) and download the result. By default it matches the file you uploaded.

Why match by key column?

Comparing row by row breaks as soon as one row is inserted or the data is sorted differently: every row after it looks changed. A key column pairs each row with its counterpart by value, so you only see real differences. You can select more than one key column when a single column is not unique, for example first name plus birth date.

Comparing in Excel itself, and where it falls short

Excel can compare files, but each method has limits:

  • View Side by Side helps you look at two files together, but you still spot the differences by eye.
  • A formula such as =A2=B2 only works when both sheets have the same rows in the same order.
  • VLOOKUP or XLOOKUP on a key column works for one column at a time, and you need a second lookup in the other direction to find rows that exist only in the other file.
  • Microsoft Spreadsheet Compare is only included in certain Office editions and runs on Windows.

This tool combines the key-based matching of a lookup with a clear report of added, removed and changed rows, right in your browser.

Frequently asked questions

How do I compare two Excel files and find the differences?

Upload both files, choose a key column that identifies each row (such as an ID or email address) and click Compare. The tool lists rows that were added, removed or changed, and shows exactly which cells differ.

Does the order of the rows matter?

Not when you match by key column. Rows are paired by their key value, so sorted differently or with rows inserted in the middle still compares correctly. Only the row position mode depends on the order.

How do I compare two CSV files?

Upload both .csv files in the same way. The delimiter (comma, semicolon, tab or pipe) is detected automatically and you can change it if needed. You can also compare a CSV file with an Excel file.

Can I compare two sheets in the same workbook?

Yes. Upload the same file twice, once as File A and once as File B, and choose a different sheet for each side.

How can I compare two Excel files without VLOOKUP?

Choose a key column and the tool does the matching for you. It pairs each row with its counterpart by key value, which is what a VLOOKUP or XLOOKUP does, but for every row and every column at once and in both directions.

Does it highlight the differences in my original file?

No. The result is a separate difference report that lists added, removed and changed rows and shows the old and new value of each changed cell. Your original files are never modified.

Which file types work?

The tool reads .xlsx, .xls and .csv files. For workbooks with several sheets you choose the sheet per file. The result can be downloaded as .xlsx, .xls or .csv.

How are values compared?

Cells are compared as text, exactly as you see them in the sheet. Formulas are compared by their displayed result. The downloaded result also contains text values.

Are my files uploaded to a server?

No. Both files are read and compared in your browser. Nothing is uploaded or stored.

Is there a size limit?

There is no fixed limit, but everything runs on your own device. Files with tens of thousands of rows work fine and very large files can be slow. The .xls format itself is limited to 65,536 rows, so choose .xlsx or .csv for big results.
